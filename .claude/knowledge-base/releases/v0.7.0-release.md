## Release notes

### Added
- **M7 — Injeção de env/secrets no run time (remove o teto de auth do M6):** cenários passam a testar APIs autenticadas — `Authorization: Bearer ${{ env.TOKEN }}` resolve o segredo no run time a partir de env vars com prefixo `HODOR_SECRET_*` (allowlist por construção; `process.env` nunca exposto inteiro). Fail-fast em var ausente. Reusa interpolação do M1 + `process.env` (stdlib). ZERO dep nova.

### Security
- **M7 — Redação por VALOR em todos os sinks:** o segredo injetado NUNCA é persistido. `redactSecretValues` (longest-first, keploy) substitui cada valor por `<redacted>` em url/headers/body/captures + response (incl. `statusText`) + `name`, cobrindo as variantes `encodeURIComponent`/`encodeURI`/JSON-escaped, no choke point antes de todo `persistRun` e no `structuredContent`. Error path redigido (`scrubSecretsFromText`). Drop de secret inválido diagnosticado por NOME (`secret_dropped`), nunca pelo valor. Mitiga o vetor SSRF+secrets (só `HODOR_SECRET_*` é injetável).
