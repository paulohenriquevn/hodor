# Milestone M8 — Fundação V3: API REST + SPA React (paridade de revisão)

## Objective (from ROADMAP.md)

Provar a arquitetura nova ponta a ponta na fatia mais fina: expor o core via uma API REST fina e subir uma SPA React (Vite + TS + shadcn/ui + Tailwind) que replica a UI de revisão atual consumindo essa API — sem perder nada do SSR nativo existente.

## Definition of done (from ROADMAP.md)

- [x] API REST fina expõe runs/diff/verdict/drafts/reviews, delega ao core (ZERO regra de domínio).
- [x] SPA React com paridade de leitura da web SSR (lista, detalhe req/resp/headers, asserts, golden, regressão).
- [x] E2E loop de revisão na SPA contra a API; SSR nativo vivo.
