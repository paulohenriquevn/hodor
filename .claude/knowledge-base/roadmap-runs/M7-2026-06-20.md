# Milestone M7 — Injeção de env/secrets no run time

## Objective (from ROADMAP.md)

Permitir testar APIs reais autenticadas injetando segredos/variáveis de ambiente na execução, sem commitar o segredo — removendo o teto do gate de regressão (M6).

## Definition of done (from ROADMAP.md)

- [x] Interpolação de env/secret (`${{ env.NOME }}`) resolve de fonte de ambiente no run time.
- [x] Segredos injetados NUNCA persistidos em runs/reviews/drafts.
- [x] E2E: cenário com auth via env contra endpoint autenticado real passa.

## Outcome

M7 entregue em v0.7.0 (PR #7, merge ac362d3, tag v0.7.0). Injeção `${{ env.NOME }}` de env vars allowlisted por prefixo `HODOR_SECRET_*`, com redação por valor em todos os sinks (incl. statusText, name, formas encodadas/JSON-escaped, error path). DIP preservada (core nunca lê SEGREDO de env; adaptador resolve via `resolveHodorSecrets`).
